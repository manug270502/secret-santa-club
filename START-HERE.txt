SECRET SANTA CLUB NETLIFY + TWILIO - INIZIA DA QUI

1) PROVA LOCALE
- Apri questa cartella in Visual Studio Code.
- Richiede Node.js 22.13 o superiore.
- Nel terminale esegui: npm start
- Apri: http://localhost:3000
- Controlli completi: npm run check

2) AGGIORNA IL SITO GIA ONLINE
Copia questi file nel repository gia collegato a Netlify, senza cancellare .git, poi:

git add .
git commit -m "Mobile, admin partecipante e inviti Twilio"
git push

Netlify pubblichera automaticamente il nuovo deploy. I Blob esistenti restano invariati.

3) CONFIGURA TWILIO
Apri prima:
docs/CONFIGURAZIONE-TWILIO-WHATSAPP.md

Servono un sender WhatsApp Twilio, un template approvato e le variabili ambiente Netlify. Le credenziali non vanno inserite nel codice o su GitHub.

4) COSA CAMBIA
- Mobile ottimizzato.
- Flag "Parteciperai anche tu?".
- Admin incluso nel sorteggio solo quando richiesto.
- Pulsante "Invia tutti" per spedire automaticamente gli inviti via Twilio.
- Stato inviato/consegnato/letto/fallito nella cabina admin.
