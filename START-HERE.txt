SECRET SANTA CLUB - NETLIFY FREE v4.0

1. Apri questa cartella in Visual Studio Code.
2. Per provarla in locale esegui: npm start
3. Apri: http://localhost:3000
4. Per verificare tutto esegui: npm run check

PER AGGIORNARE IL SITO LIVE

Copia questi file nel repository gia collegato a Netlify, senza cancellare .git, poi:

npm run check
git add .
git commit -m "Inviti WhatsApp gratuiti click-to-chat"
git push

Netlify pubblichera il nuovo deploy automaticamente.

COME FUNZIONANO GLI INVITI

- "Apri WhatsApp" apre la chat esatta con messaggio e link gia pronti.
- Devi soltanto premere Invia dentro WhatsApp.
- "Apri il prossimo" procede una persona alla volta.
- La spunta indica che la chat e stata aperta, non che il messaggio sia stato consegnato.
- Non servono servizi esterni, credenziali o pagamenti.
