SECRET SANTA CLUB - NETLIFY FREE v6.0
====================================

AVVIO LOCALE
1. Apri questa cartella in Visual Studio Code.
2. Esegui: npm start
3. Apri: http://localhost:3000

VERIFICA COMPLETA
npm run check

AGGIORNAMENTO DEL SITO LIVE
1. Copia questi file nel repository gia collegato a GitHub/Netlify.
2. Non eliminare la cartella nascosta .git.
3. Esegui:

   npm run check
   git add -A
   git commit -m "Control Center super admin e ottimizzazioni v6"
   git push

CONTROL CENTER
URL: https://TUO-SITO.netlify.app/super-admin

Prima del primo accesso configura su Netlify:
- SUPERADMIN_USERNAME
- SUPERADMIN_PASSWORD_HASH
- SUPERADMIN_SESSION_SECRET
- SUPERADMIN_SESSION_HOURS (facoltativa, default 8)

Genera l'hash:
npm run superadmin:hash -- 'Una password lunga e unica'

Genera il segreto:
node -e "console.log(require('node:crypto').randomBytes(48).toString('base64url'))"

IMPORTANTE
- Non inserire mai la password in chiaro su GitHub.
- Gli store Blob restano secret-santa-data-v2 e secret-santa-media-v2.
- Gli eventi e le foto esistenti non vengono cancellati.
- Dopo aver aggiunto o modificato le variabili Netlify, avvia un nuovo deploy.
