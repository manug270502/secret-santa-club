SECRET SANTA CLUB - NETLIFY FREE v5.0

1. Apri questa cartella in Visual Studio Code.
2. Per provarla in locale esegui: npm start
3. Apri: http://localhost:3000
4. Per verificare tutto esegui: npm run check

PER AGGIORNARE IL SITO LIVE

Copia questi file nel repository gia collegato a Netlify, senza cancellare .git, poi:

npm run check
git add -A
git commit -m "Budget, recupero inviti e profili regalo"
git push

Netlify pubblichera automaticamente il nuovo deploy.

NOVITA PRINCIPALI

- budget facoltativo per regalo;
- correzione del campo data su mobile/iPhone;
- pagina /my-events per ritrovare le feste dal numero di telefono;
- codice elfo personale per proteggere link e abbinamento;
- colore, passioni, stile regalo e cose da evitare;
- card delle preferenze nella dashboard comune.

EVENTI PRECEDENTI

Dopo il deploy apri una volta la cabina admin di ogni vecchio evento. Il sistema crea i codici elfo e l'indice di recupero senza perdere dati. Per i vecchi inviti, reinvia il messaggio oppure comunica il codice mostrato in admin.
